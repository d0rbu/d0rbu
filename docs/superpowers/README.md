# Superpowers planning archive

This directory keeps the planning records used during milestone work:

- `specs/` contains approved design notes.
- `plans/` contains implementation plans and task breakdowns.

These files are intentionally preserved as a decision trail. Some older entries
describe designs that were later revised, such as bundled `content/*.json` or a
`questionary` menu. Treat newer specs/plans and the current source tree as the
authority when they disagree.
